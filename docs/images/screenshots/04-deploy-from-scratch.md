# Deploying from Scratch

This is the exact workflow used to deploy the application to SAP BTP (Cloud Foundry).

## Prerequisites
* SAP BTP Trial Account
* SAP Business Application Studio (BAS)
* Cloud Foundry CLI, MTA Build Tool (`mbt`), CAP CDS (`@sap/cds-dk`)
